⚙️ 指令编解码

rvcodec.js
基于 rvcodec.js（LupLab @ UC Davis），支持 RV32 / RV64 / RV128 与压缩指令。 输入汇编指令或机器码，加载后即可查看编解码结果。

🚨 异常 & 中断

mcause / scause / vscause
mcause / scause 最高位表示陷阱类型：1 = 中断，0 = 异常，低位为编码。
例如 0x8000000000000005 = 中断 5（S 定时器中断）；0x000000000000000d = 异常 13（Load 页错误）。点击表格行可快速解码。

🗺️ 虚拟地址转换

Bare / Sv39 / Sv48 / Sv57
选择分页模式后输入虚拟地址，按 RISC-V 标准拆解为各级 VPN 与页内偏移。 每个 PTE 固定 64 位（8 字节），每个页表恰有 512 项（4 KiB 一页），每级 VPN 为 9 位。

📋 CSR 字段展开

Field Decomposer
输入 CSR 名称 和 数值，自动展开为对应的字段（域段）， 显示每个字段的 bit 范围、位宽、当前值 及含义。非零字段高亮显示。

📄 PTE Entry 解析

Sv39 / Sv48 / Sv57 · 64-bit PTE
输入 64 位 PTE 数值，按 RISC-V 标准展开为每个域段： PPN（44 位，分 PPN[2:0]）、标志位 V / R / W / X / U / G / A / D、 RSW、PBMT、N。

🔒 PMP 配置寄存器

pmpcfg0 / pmpcfg2 (RV64)
输入 pmpcfg 的 64 位数值，按 8 位一组拆分为 8 个 pmpXcfg。 每个条目包含 L（锁定）、A（地址匹配模式）、X / W / R 权限。

🔧 CSR 指令识别

Zicsr · funct3 编码
输入 CSR 指令的 funct3（3 位，位于指令 bit 14:12），识别对应的 CSR 指令名与语法。 例如 b101 → csrrwi；0b010 → csrrs。
